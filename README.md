# OpalBar-Win10

Tray app that styles the Windows 10 taskbar: Clear, Blur, Acrylic, Color or Solid effect with a tint color and density.

Run `OpalBar10.exe`. Left click on the tray icon opens settings; right click shows Settings, Enabled, Hide and Exit. Running the exe again opens settings of the running copy, which also brings the settings back after "Hide".

Options: effect, tint color, tint density (0 % turns Blur and Acrylic into a clear taskbar), solid taskbar while a window is maximized, apply to all monitors, start with Windows, tray icon, English or Russian, and a button that checks GitHub for a newer release and replaces the exe in place.

Settings are saved in `OpalBar10.ini` next to the exe, diagnostics go to `OpalBar10.log`.
