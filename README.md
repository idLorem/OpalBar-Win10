# OpalBar-Win10

Tray app that styles the Windows 10 taskbar: Clear, Blur, Acrylic or Color effect with a tint color and density.

Run `OpalBar10.exe`. Left click on the tray icon opens settings; right click shows Settings, Enabled, Hide and Exit. Running the exe again opens settings of the running copy, which also brings the settings back after "Hide".

Settings are saved in `OpalBar10.ini` next to the exe, diagnostics go to `OpalBar10.log`. The interface is English or Russian.
